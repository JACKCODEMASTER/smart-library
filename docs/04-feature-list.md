# Feature List

For each feature: what it is, how it works, and which 4th Industrial Revolution (4IR) technology powers it. (Full visual treatment lives on `features.html`.)

## 1. AI Reading Tutor
- **What:** Each tablet runs an AI tutor that teaches reading directly in the child's native language (e.g. Hausa, Zarma).
- **How it works:** Generative AI produces original stories, vocabulary drills, and sentence-reading passages on the fly, calibrated to the child's level, and generates supporting images so new vocabulary is reinforced visually, not just textually.
- **4IR Technology:** Generative AI.
- **Barrier removed:** No access to a personal tutor or native-language instructional materials.

## 2. Adaptive Lesson Difficulty
- **What:** The system automatically raises or lowers difficulty and resurfaces weak spots.
- **How it works:** A predictive model logs every answer — correctness, number of attempts, time of day — and uses that history to decide the next lesson's difficulty (e.g., a 90%+ spelling quiz streak triggers a level-up; repeated misses trigger remedial practice).
- **4IR Technology:** Machine Learning.
- **Barrier removed:** One-size-fits-all curriculum that leaves faster or slower learners behind.

## 3. Points, Levels & Game Time
- **What:** Kids earn points for completing lessons, level up, and unlock game time on the same device once they've hit a point threshold.
- **How it works:** Gamified progression logic (app-layer, not AI) sits on top of the adaptive lesson engine — it's the behavioral hook that keeps kids returning daily, similar to Lexia's reward structure.
- **4IR Technology:** Supported by Machine Learning outputs (progress data) feeding a gamification layer.
- **Barrier removed:** No built-in incentive to keep practicing reading outside of a formal classroom.

## 4. Solar + LiFePO₄ Power System
- **What:** Rooftop solar panels charge a long-life Lithium Iron Phosphate (LiFePO₄) battery that runs tablets, router, cameras, and sensors all day.
- **How it works:** IoT power/battery sensors continuously report charge level so the team knows before a shed's power could fail.
- **4IR Technology:** Internet of Things (power monitoring).
- **Barrier removed:** No reliable electrical grid in rural deployment sites.

## 5. 4G/5G Connectivity + Offline Mini PC
- **What:** A Wi-Fi router connects tablets to the internet via 4G/5G for syncing; when connectivity drops, a small on-site mini PC serves pre-downloaded lessons, quizzes, and reading assignments.
- **How it works:** IoT connectivity sensors detect signal loss and automatically fail over tablets to the local mini PC content library.
- **4IR Technology:** Internet of Things (connectivity failover).
- **Barrier removed:** Inconsistent or unavailable internet access in remote regions.

## 6. Fingerprint ID + Camera Security
- **What:** Each child registers a fingerprint (after an enrollment photo confirms age) to unlock a tablet; cameras monitor the library space.
- **How it works:** Fingerprint hardware authenticates the registered user per session; if a tablet is removed from the library's defined boundary, it auto-locks and shuts down; cameras provide footage for identifying theft.
- **4IR Technology:** Internet of Things (biometric + camera sensors).
- **Barrier removed:** Device theft and unauthorized/unsafe use.

## 7. Central IoT Monitoring Dashboard
- **What:** A live dashboard shows power levels, tablet activity, attendance, and maintenance alerts across every library site.
- **How it works:** All on-site sensors (power, usage, security) sync data to a central system the Smart Library team checks remotely.
- **4IR Technology:** Internet of Things + Machine Learning (for maintenance/anomaly prediction).
- **Barrier removed:** No way to staff or manually monitor dozens of unattended, rural locations.
